# Homework 1 — Basic unvalidated loop

Read `basic-unvalidated-loop.feature` and build it.

How you build it is up to you. It does not have to be a bash loop, and we
would rather it weren't. What matters is that the behaviour in the feature
file is true of the thing you end up with.

Point it at a spec for a game of Tetris that runs in the terminal. Once it
works, change the spec and run it again.

You will keep this. The next homework adds behaviour to the factory you
built here.
